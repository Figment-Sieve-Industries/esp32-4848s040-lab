Flash the Guition ESP32-4848S040 from your browser

Install prebuilt firmware over USB. No PlatformIO, no toolchain. For the 4" 480x480 touch board with the ESP32-S3 N16R8 (16 MB flash, 8 MB PSRAM), sold as Guition ESP32-4848S040C_I.

Before you start

  • Chrome or Edge on a desktop computer (Windows, macOS, Linux, ChromeOS). Web Serial is not available in Firefox, Safari, or on phones and tablets.
  • A USB-C data cable (a charge-only cable shows no port).
  • CH340 driver. The board uses a CH340C USB-serial chip. If no port appears in the chooser, install the driver from the chip maker, WCH: CH341SER. Windows 10/11 usually does this itself; macOS and Linux generally need nothing.
  • Close any serial monitor that has the port open.

Back up your factory firmware first. Installing replaces everything on the flash, and the "erase" option wipes it. Keep the vendor demo so you can go back: flash backup and restore (D-18) and programming and flashing.

How it works

  1. Plug the board in and click an install button.
  2. Pick the serial port (look for "USB-SERIAL CH340") and confirm.
  3. Tick "Erase device" for a clean install (recommended when switching projects), then install. It takes a minute or two; do not unplug.
  4. The board restarts into the new firmware.

Each image is a single merged 16 MB-layout file written at address 0 (bootloader, partition table, app). Checksums are in SHA256SUMS.txt. Every image is built by CI from the tagged source; nothing personal is inside.
